## Что нового

- **Пульт — обычная программа Windows.** Своё окно с тёмным заголовком, своя кнопка на панели задач, ярлыки в «Пуске» и на рабочем столе. Внутри — встроенный в Windows 10/11 движок WebView2: без вкладок, адресной строки, меню браузера и предложений перевести страницу.
- Окно запоминает размер и положение. Закрытое окно оставляет программу в трее и освобождает память, драйвер работает как прежде.
- Повторный запуск ярлыка выводит открытое окно на передний план.
- Трейлер — ниже, в файлах выпуска.

## What’s new

- **The panel is a normal Windows app.** Its own window with a dark title bar, its own taskbar button, Start menu and desktop shortcuts. Inside is WebView2, the engine built into Windows 10/11: no tabs, address bar, browser menus or offers to translate the page.
- The window remembers its size and position. Closing it leaves the app in the tray and frees the memory; the driver keeps working as before.
- Starting the shortcut again brings the open window to the front.
