## Что нового

Первый публичный выпуск C01U Pro Studio — бесплатного драйвера-обработчика для USB-микрофона Samson C01U Pro.

- Обработка голоса прямо в Windows: улучшенный звук получают все программы — Discord, OBS, Zoom, Telegram, игры.
- Шумоподавление без нейросетей, гейт, 10-полосный эквалайзер, компрессор, де-эссер, поп-фильтр, фильтр гула, автоуровень, лимитер.
- Эффекты голоса: робот, рация, телефон, сдвиг высоты, эхо, реверберация.
- Пульт в стиле студии 70-х: прослушка себя, A/B-тест «до и после», диагностика с исправлением в один клик, инструкция.
- 25 языков интерфейса, в том числе все языки СНГ.
- Автообновление: новые версии ставятся сами, когда микрофон свободен, и проверяются цифровой подписью автора.

## What’s new

The first public release of C01U Pro Studio, a free voice processing driver for the Samson C01U Pro USB microphone.

- Voice processing inside Windows: every app gets the improved sound — Discord, OBS, Zoom, Telegram, games.
- Noise suppression without neural networks, gate, 10-band equalizer, compressor, de-esser, pop filter, hum filter, auto level, limiter.
- Voice effects: robot, walkie-talkie, phone, pitch shift, echo, reverb.
- A 1970s studio style control panel: listen to yourself, before/after A/B test, diagnostics with one-click fixes, a short guide.
- 25 interface languages.
- Automatic updates: new versions install by themselves while the microphone is free and are verified with the author’s digital signature.

**Установка:** скачайте `C01UProStudio-1.0.0.exe` ниже, запустите и нажмите «Установить драйвер». Windows может показать «Windows защитил ваш компьютер» (программа не подписана сертификатом) → «Подробнее» → «Выполнить в любом случае». Дальше программа обновляется сама.

**Install:** download `C01UProStudio-1.0.0.exe` below, run it and press “Install driver”. Windows may show “Windows protected your PC” (the app has no code signing certificate) → “More info” → “Run anyway”. After that the app keeps itself up to date.

`update.txt` и `update.txt.sig` — служебные файлы автообновления / service files for automatic updates.
