# Промо-ролик C01U Pro Studio

Ролик ~31 с, 1920×1080, 60 к/с, русская и английская версии. Склейки стоят на долях трека
(120 BPM, первая доля 0,19 с, дроп 13,19 с, финальный удар 29,19 с). Сюжет: «старый звук →
обновление → новый звук», главная сцена — ретро-телевизор 70-х.

- 0–5,7 с: телевизор включается, на экране чёрно-белый C01U Pro в ряби, метки шума и грязная
  волна — «Годами без обновлений». На ударах помехи и щелчки каналов: «Шум. Гул. Щелчки.»
- 5,7–8,2 с: на экране современный установщик с прогрессом — «Пора обновиться». Крупно ручка
  каналов: щелчок на 8,19 с, лампа зелёная.
- 8,2–13,2 с: картинка цветная, «Новые настройки», камера влетает в кинескоп (видна маска пикселей).
- 13,19 с, дроп: микрофон и логотип.
- 15–23 с: настоящий пульт на экране телевизора (наезд на VU-стрелки), студийная цепочка,
  эквалайзер, диагностика.
- 23–29 с: программы как телеканалы, табло языков, обновление само по себе.
- 29,19 с: финальная плашка, потом кинескоп гаснет в точку (уже в тишине после трека).

## Музыка

Трек сгенерирован в Suno под этот ролик. В репозитории он не хранится — положите его в
`promo/music/c01u-suno.mp3` и посчитайте данные для визуала (громкость и спектр на каждый кадр):

```bash
python promo/analyze.py promo/music/c01u-suno.mp3 promo/music/track.json
```

## Рендер

Нужны Node.js, Microsoft Edge и `ffmpeg` в PATH.

```bash
cd promo && npm install && cd ..
node promo/render.js               # promo/out/C01U-Pro-Studio-promo-ru.mp4
node promo/render.js --lang en     # английские подписи
```

Флаги: `--blur 4` — размытие движения из N подкадров (`--blur 1` быстрее); `--stills 1,8.2,13.3` —
только PNG-кадры на указанных секундах в `promo/out/stills`; `--dbg` — время и номер доли в кадре.

Посмотреть страницу в браузере: `node promo/server.js` → http://127.0.0.1:47900/promo/index.html
(время в ней стоит, пока его не двигает рендерер: `__step(мс)` в консоли).

## Как устроено

- `clock.js` — виртуальные часы (из промо KeyShow): подменяют таймеры, `performance.now`
  и анимации, чтобы каждый кадр считался ровно в свой момент.
- `promo.js` — сценарий: комната и телевизор (HTML/CSS, камера — трансформация сцены), титры,
  карточки на экране. Время задаётся в долях: `beat(n)`.
- `mic.js` — 3D-модель Samson C01U Pro (Three.js) по фотографиям. Её кадр копируется на экран
  телевизора (чёрно-белый до щелчка, цветной после) или показывается на весь кадр.
- Настоящий пульт (`../web`) открыт во фрейме на экране. `server.js` подставляет в него те же часы
  и `ui-shim.js`, который отвечает на запросы к API снимком состояния из `data/` и кормит
  индикаторы спектром трека — стрелки и LED-спектр двигаются в такт музыке.
- `render.js` — Edge без окна (видеокарта через ANGLE) → JPEG-кадры → ffmpeg (H.264 + AAC).
